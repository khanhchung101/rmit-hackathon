# Contributor workflow

Please work in small changes aligned to `tasks/backlog.csv`. Never paste real Tide dokens, private keys, user invoices or provider credentials in issues/repo. Each security claim should link to evidence and identify mock vs real mode. Run `npm test`, `npm run validate:fixtures` and `npm run security`. Real Tide integration is subject to Step 0 G4 and separate external verification review. Follow `AGENTS.md` and `PLAN.md` first.
