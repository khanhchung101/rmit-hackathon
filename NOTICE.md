# Notice

Leash is an independent hackathon prototype, not a Tide, Visa, Circle or Fireblocks product and not a production payment system. The project includes no Tide SDK source files and no pretrained models. The C# policy file is an **intent template**, not a deployed contract. Consult third-party licenses and current terms before distributing third-party dependencies/model weights. Mock mode uses a process-local private key for **testing only** and does not reproduce Tide's threshold cryptography.
